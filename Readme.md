# Student Marks Analysis 📊

A beginner-friendly Python project that analyzes student marks and calculates the total, average, highest, and lowest marks.

## 📌 Project Overview

This project was created as part of a Python data processing task.

The program stores student marks using a Python list and performs basic statistical calculations using built-in Python functions.

## 🎯 Objectives

- Store student marks using a Python list
- Calculate total marks
- Calculate average marks
- Find the highest marks
- Find the lowest marks
- Practice basic Python data processing

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- VS Code
- Git & GitHub
